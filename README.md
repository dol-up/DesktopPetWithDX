# DesktopPetWithDX

현재 개발 중인 프로젝트입니다. 구현한 기능과 확인이 남은 항목은 아래 문서에 구분해 기록합니다.

Win32와 DirectX 11로 FBX 모델을 표시하는 데스크톱 펫입니다. 모델을 왼쪽 버튼으로 잡아 옮기고 오른쪽 버튼으로 드래그해 회전합니다.

오른쪽 버튼으로 더블클릭하면 설정창을 엽니다. **애니메이션** 탭에서 대기·잡힘·낙하·착지·걷기 클립, 재생 배속과 전환 시간을 지정하고 클립을 미리 볼 수 있습니다. 착지는 한 번, 걷기는 반복해서 재생합니다.

**자율 걷기** 탭에서 제자리 걷기 클립을 지정하고 ‘자율 걷기 사용’을 켠 뒤 설정창을 닫으면 바닥에서 대기·방향 전환·걷기·정면 복귀를 반복합니다. 한 번의 걷기를 마치면 멈춰서 정면으로 돌아온 뒤 쉽니다. 처음 사용하는 모델은 꺼짐이 기본값입니다. 사용할 걷기 클립이 없으면 이동하지 않습니다. 펫 창에 포커스를 준 뒤 `B` 키로도 켜거나 끌 수 있습니다.

이동 속도·걷기 배속·대기 시간·걷는 시간·방향 전환 시간·정면 방향 보정을 모델별로 설정할 수 있습니다. 잡기·회전·수동 조작·설정창·미리보기·착지 중에는 자율 걷기를 멈춥니다.

애니메이션과 걷기 설정은 저장 버튼, 변경 후 설정창 닫기, 모델 변경, 정상 종료 시 `animation_settings.txt`에 함께 저장합니다. 이전 버전의 애니메이션 설정도 읽으며, 마지막 모델과 창 위치는 `last_model.txt`에 저장합니다. 모델 텍스처는 압축된 내장 텍스처만 읽습니다.
