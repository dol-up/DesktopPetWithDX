# 기능 구현 현황

기준: 2026-10-02. 사용 방법·설계·검증 범위는 [애니메이션 런타임](Animation_Runtime.md), [자율 걷기](Autonomous_Walking.md), [개발 학습 가이드](DEVELOPMENT_STUDY_GUIDE.md)를 참고한다.

## 완료

- [x] 화면 Ray, AABB·삼각형 검사와 현재 애니메이션 자세의 CPU 스키닝 피킹
- [x] 모델 클릭 드래그, 크기 변경 시 좌표 보정, quaternion 우클릭 회전
- [x] K+L 수동 모드와 R 회전 초기화
- [x] 시간 기반 중력, 드래그 중 정지, 낙하·새 착지 이벤트 구분
- [x] 모니터 작업 영역과 바인드 자세 하단으로 바닥 정렬
- [x] normal 기반 라이팅 제거와 premultiplied alpha 출력 유지
- [x] 압축 내장 텍스처 로딩, 외부 텍스처 자동 검색 제거
- [x] Assimp 클립·노드·본·가중치·키 데이터의 독립 소유
- [x] Animator의 TRS 보간, 반복·일시정지·시간 이동·자세 전환
- [x] GPU 스키닝 팔레트와 CPU 피킹의 동일 자세 사용
- [x] 대기·잡힘·낙하·착지·걷기 행동 상태와 클립 선택·배속
- [x] 별도 Win32 설정 창의 ImGui 애니메이션·자율 걷기 탭과 미리보기
- [x] 모델별 설정 저장·복원, 클립 이름·중복 순번 저장, 임시 파일 교체
- [x] 마지막 모델과 창 위치 저장·복원, 구형 위치 파일 호환

## 자율 걷기 1~6단계 완료

- [x] 1단계: 대기·회전·이동 판단, 시간 범위·방향 난수, 중단 후 재대기
- [x] 2단계: 소수 픽셀 누적 좌우 이동, 모델 가로 범위·작업 영역 경계 처리
- [x] 3단계: 자동 yaw, 사용자 회전 보존, 회전 중 바닥 유지
- [x] 4단계: 제자리 Walk 연결, 상태 우선순위·반복 재생, 배속·크기에 맞춘 속도
- [x] 5단계: 걷기 설정 탭·B 키, 모델별 옵션·활성화 저장, 버전 1→2 호환
- [x] 6단계: 합성·파일·실제 창·WARP·ImGui 입력 통합 검사, 문서 최신화
- [x] 걷기 구간 종료 후 정면으로 부드럽게 복귀하고 Idle로 대기, 복귀 중 이동 정지·중단 처리

메인 앱·테스트의 Debug/x64 빌드와 로컬 FBX 7개·74개 클립의 검사가 통과했다. 걷기가 있는 4개 모델의 이동·재생 연결과 없는 3개 모델의 이동 제한을 확인했다.

## 수동 확인 대상

- [ ] 실제 데스크톱의 마우스 드래그·우클릭 회전·B 키 조작
- [ ] 여러 모니터·서로 다른 DPI에서 드래그, 작업 영역 변경·모니터 제거
- [ ] 앱 재실행 후 모델별 설정과 마지막 위치 복원
- [ ] 다양한 모델의 정면 보정·보폭과 실제 이동 속도 조정

## 선택 확장

- [ ] 투명 텍스처 alpha 영역을 제외하는 정밀 피킹
- [ ] 발 고정 IK와 모델 보폭의 자동 분석
- [ ] 루트 모션 추출·제자리 재생 변환, 클립 중간 경로 검사
- [ ] 모프·메시 교체 애니메이션 지원

별도 Win32 팝업 메뉴는 현재 구현 대상으로 두지 않는다. 클립 지정과 종료·저장은 기존 설정 화면과 단축키에서 처리한다.
